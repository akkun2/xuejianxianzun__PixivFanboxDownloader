# 把更新说明文本转换为 HTML 格式

每次发布更新之前，我会先整理出 Markdown 格式的更新说明文本，然后转换成 html 格式，以便在浏览器里显示。

## 输入文本

以下是一份 Markdown 格式的更新说明：

```
### ✨在保存投稿中的文字时，新增了 HTML 格式

之前该设置只有 TXT 格式，查看时不会显示投稿里的图片、视频等内容。新增的 HTML 格式可以显示这些内容，阅读体验接近 Fanbox 的网页浏览效果。

感谢 [Eganchiyu](https://github.com/Eganchiyu) 提交了该功能。

### ✨新增设置：保存投稿中的评论

感谢 [Eganchiyu](https://github.com/Eganchiyu) 提交了该功能。
```

## 转换规则

为了将其转换成 html 格式，需要进行以下处理：
- 执行**一次**全局替换，把连续的两个换行替换成 1 个换行，使排版更加紧凑。注意：有些文本之间可能有 3 个换行，这是故意的。它们在替换一次之后还剩下 2 个换行，不需要再次替换。
- 在每个换行处添加一个 `<br>` 标签。并且保持原本的换行格式，即不要把所有文本压缩到一行。原本是单独一行的，现在仍然保持单独一行。
- 对于标题行，之前使用了三级标题的符号 `### `，现在把标题行的内容改为 `<strong>原标题内容</strong>` 格式
- 对于每个反引号对（用于高亮显示关键词），都改为 `<span class="blue">原内容</span>` 的格式。
- 对于 Markdown 格式的链接 `[]()`，把它们转换成 HTML 的 `A` 标签，并且设置 `target="_blank"` 属性。

## 处理转换结果

先生成转换结果（它是简体中文文本），然后用它翻译并生成下载器的 i18n 系统里所有语言的文本（按顺序依次是：简体中文、繁体中文、英语、日语、韩语、俄语）。最后把结果填充到 `src\ts\langText.ts` 的 `_更新说明5_0_0` 属性的数组里。
